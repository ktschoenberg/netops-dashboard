# test-projects

Standalone concept prototypes — kept separate from the production dashboards
(netops, itrm, spp, pmo, etc.) at the repo root.

Each subfolder is a self-contained single-file HTML app.

- **trellis/** — "Trellis" Talent-First Internal Mobility MVP. A clickable concept
  tool demonstrating a scientific, skills-based matching engine + consumer-grade
  internal mobility marketplace ("Talent First, Resume Second"). Styled to match
  the Network Operations dashboard design system.
